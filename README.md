
# Mundo Pet 🐾

## Sobre o projeto

O Mundo Pet é um site desenvolvido para um petshop fictício especializado em produtos e serviços para cães e gatos.

O projeto tem como objetivo apresentar produtos, divulgar serviços de banho e tosa e permitir que os clientes realizem o cadastro de seus dados e solicitem agendamentos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Funcionalidades

- Página inicial com carrossel de imagens.
- Apresentação de produtos para cães e gatos.
- Divulgação dos serviços de banho e tosa.
- Formulário de cadastro do responsável e do pet.
- Escolha do serviço e modalidade de entrega.
- Seleção de data e horário para agendamento.
- Validação dos dados e mensagem de confirmação.

## Organização dos arquivos

- `index.html`: estrutura principal do site.
- `css/estilo.css`: estilos e identidade visual.
- `js/script.js`: validações e funcionalidades do formulário.
- `assets/`: imagens utilizadas no site.
